# 동물농장 멀티플레이어 가이드

서버 0대, WebRTC 기반 P2P. 친구와 농장을 공유해요.

## 1. 친구 코드 공유 방법

1. 게임 하단 `👥친구` 버튼 → 모달 오픈.
2. 상단 박스에 표시된 **`FARM-XXXXXX`** 6자리 코드가 내 농장 코드.
3. `📋 복사` 버튼 → 카카오톡/문자/디스코드 등 아무 메신저에 붙여넣기.
4. 친구가 자기 게임에서 같은 모달을 열고 `친구 코드 입력` 칸에 내 코드를 붙여넣고 `🚪 방문하기` 누르면 끝.

## 2. 방문 시 보이는 것 / 할 수 있는 것

### 보이는 것
- 친구 농장의 **그리드, 동물, 작물, 건물**.
- 친구의 **돈/계절/일차** (UI 상단).

### 할 수 있는 것 (방문자)
- `💰 100코인 선물` — 내 돈에서 100원 차감, 친구 농장에 +100원.
- `🌾 작물 5개 선물` — 친구 농장에 +150원 상당.
- `✏️ 방명록 남기기` — 1줄(최대 40자) 메시지를 친구 화면에 토스트로 표시.

### 할 수 없는 것
- 작물 심기/동물 배치/건물 짓기 등 **편집 일체 차단**.
- 방문 중 `💾저장` 시 "방문 중에는 저장할 수 없어요" 토스트.
- `🚪 나가기`(상단 배너) 또는 `🏠 내 농장으로`로 즉시 복귀, 내 농장 상태는 그대로 보존돼요.

## 3. 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| `오프라인: 멀티플레이 사용 불가` | PeerJS CDN(unpkg) 로드 실패. 인터넷 연결 / 광고 차단기 / 회사 방화벽 확인. |
| `친구를 찾을 수 없어요` | (1) 친구가 게임을 켜고 모달을 한 번이라도 열었는지 확인 (peer 등록 필요). (2) 코드 오타. (3) 친구가 다른 농장을 방문 중이면 호스트 역할 불가. |
| 연결되지만 농장 안 보임 | 대칭 NAT(이동통신망) 환경. WiFi로 전환하거나, 한쪽이라도 데스크톱/공용 WiFi 사용. PeerJS 기본 설정엔 TURN 서버 없음. |
| 방화벽 차단 | UDP 아웃바운드(브라우저 WebRTC) + 443/TCP(PeerJS 시그널링) 허용 필요. 사내망에서 자주 막힘. |
| 모바일에서 코드 복사 안됨 | iOS Safari는 `clipboard.writeText` 권한 요구. 코드를 길게 눌러 직접 복사. |
| 연결 후 갑자기 끊김 | 호스트 탭 백그라운드 → 일부 모바일 브라우저가 WebRTC 일시 중단. 호스트가 게임 화면을 켜둔 채 방문받기. |

## 4. 보안 / 프라이버시

- **peer.id 직접 노출 안 됨** — 화면엔 6자리 단축 코드만. 내부적으로 `farmdir-<코드>` 디렉토리 peer가 실제 peer.id를 응답.
- **방문자는 읽기 전용** — 호스트 데이터는 직렬화된 스냅샷만 전송, 호스트 G 객체에 직접 쓰기 불가.
- **선물은 호스트 동의 없이 적용** — 악의적 친구가 음수 선물을 보낼 수 있는지 검토했으나, 호스트 측에서 `+100`/`+150` 하드코딩이라 안전.
- **로그/개인정보 전송 없음** — 그리드/동물/작물/건물/돈/계절만 송신.

## 5. 한계
